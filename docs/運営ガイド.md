# Minecraft Cooks 運営ガイド

**2026/11/22更新版**

Minecraft Cooks は、サーバーで遊ぶチーム対抗の料理ミニゲーム。一度用意しておけば、何回でも遊べる。このガイドは、遊べるようにするまでの準備と、遊ばせ方を順番に書いた手順書。コマンドはすべて `minecraft-cooks.admin` 権限(初期値は OP)が必要。

- **最初に1回だけやること**: 0〜2章(プラグインを入れる、リソースパックを公開する、キッチンを建てて登録する)
- **遊ぶたびにやること**: 3〜4章(チームを分ける、試合を始める)
- **必要なときだけ**: 5〜7章(設定やレシピを変える、困ったとき)

ここでは、ミニゲーム1回ぶん(クイックマッチなら1ラウンド、ノーマルマッチなら3ラウンド)を「試合」と呼ぶ。

## 0. 用意するもの(最初に1回だけ)

- Paper 1.21.11 のサーバー(Java 21)
- `build/libs/minecraft-cooks-0.1.0.jar` を `plugins/` に入れる
- 一度起動すると `plugins/minecraft-cooks/` に次のファイルができる

| ファイル | 中身 | 編集のしかた |
| --- | --- | --- |
| `config.yml` | リソースパックの URL、試合後に戻す場所 | テキストで編集して再起動 |
| `settings.yml` | 時間・点数などの数値 | `/cg settings` の画面で変える |
| `recipes.yml` | 食材・料理・レシピ | テキストで編集して `/cg reload` |
| `messages.yml` | プレイヤーに見える文章 | テキストで編集して `/cg reload` |
| `kitchens.yml` | 登録したキッチン | 自動で保存される(直接さわらない) |

## 1. リソースパックを公開する(最初に1回だけ)

1. このリポジトリの `resourcepack/` フォルダをコピーする
2. `resourcepack/assets/minecraft-cooks/textures/item/` に、42個の PNG を置く(識別子は `docs/textures.md`)
3. `resourcepack` の**中身**(`pack.mcmeta` と `assets`)を zip にする。フォルダごと zip にしないこと
4. zip を、直接ダウンロードできる URL に置く(GitHub のリリース、Dropbox の `dl=1` リンクなど)
5. `config.yml` の `resource-pack.url` に URL を書いて、サーバーを再起動する
   - `sha1` は空のままでよい。起動時にダウンロードして計算し、ログに出す。そのログの値を `sha1` に書いておくと、次からはダウンロードしない
   - zip を差し替えたら、`sha1` を空に戻すか新しい値にする

`pack.mcmeta` の形式番号は 1.21.11 の 75 にしてある。

## 2. キッチンを建てて登録する(最初に1回だけ)

キッチンは、まず1つを建てて登録し、残りは建物をコピーしてから `clone` で設備をコピーするのが早い。

### 2-1. 1つ目を登録する

```
/cg kitchen create kitchen-1 1番キッチン
/cg wand kitchen-1 area
```

- 範囲ワンドで、キッチンの対角の2点をクリックする(左クリックで1点目、右クリックで2点目)
- キッチンの中のスポーンさせたい場所に立って `/cg kitchen setspawn kitchen-1`

設備は種類ごとにワンドをもらって、置きたい場所のブロックを右クリックする。そのブロックが見えないバリアブロックに変わり、上に設備の見た目が出る。

```
/cg wand kitchen-1 box_meat
/cg wand kitchen-1 cutting_board
/cg wand kitchen-1 counter 1
/cg wand kitchen-1 counter 2
/cg wand kitchen-1 counter 3
```

| 種類 | 設備 |
| --- | --- |
| `box_meat` `box_fish` `box_veg` `box_noodle` `box_rice` | 食材箱 |
| `cutting_board` | まな板 |
| `pan` | フライパン |
| `pot_boil` `pot_steam` `pot_stew` `pot_set` | 茹で鍋・蒸し鍋・煮込み鍋・固め鍋 |
| `fryer` | フライヤー |
| `plate` | 皿(盛り付け台) |
| `counter <番号>` | 納品場所(1〜3。注文の件数と同じ数だけ) |
| `trash` | ゴミ箱 |

- 間違えたら、同じキッチンのワンド(種類はどれでもよい)で設備を**左クリック**すると解除できる
- 3店舗すべてを遊ぶなら、9品を作るのに必要な設備が全部いる(食材箱5種、まな板、フライパン、鍋4種、フライヤー、皿、納品場所、ゴミ箱)

### 2-2. 2つ目以降をコピーする

1. 建物を WorldEdit などでコピーする(設備のバリアブロックはコピーしなくてよい)
2. コピー先のキッチンを作り、範囲だけ登録する

```
/cg kitchen create kitchen-2 2番キッチン
/cg wand kitchen-2 area
```

3. 設備をコピーする。範囲の角のずれぶん、設備がずれて登録される。コピー先にスポーンがなければ、スポーンもずらしてコピーする

```
/cg kitchen clone kitchen-1 kitchen-2
```

4. `/cg kitchen list` で、全キッチンの設備の数とスポーンを確かめる

### 2-3. 試しに遊ぶ

```
/cg practice kitchen-1 chinese
/cg practice stop
```

ひとりでそのキッチンを試せる。持ち物は消え、アドベンチャーモードになる(終わるとゲームモードは戻る)。

## 3. チームを分ける(遊ぶたびに)

1. 参加しない人(運営・観戦)を指定する: `/cg exclude add <名前>`
2. 自動で分ける: `/cg team auto`
   - オンラインの人をランダムに5人ずつ分ける(最大8チーム)。余った人は観戦になる
   - 編成と観戦者の一覧が、全員のチャットに出る
3. 必要なら手で直す

```
/cg team move <名前> team-2
/cg team add team-3 <名前>
/cg team remove <名前>
/cg team name team-1 ドラゴンズ
/cg team color team-1 red
/cg team kitchen team-1 kitchen-1
/cg team list
```

- キッチンを指定しなかったチームには、試合開始のときに空いているキッチンがランダムに割り当てられる
- 5人でないチームがあっても開始できる(警告は出る)

## 4. 試合を進める(遊ぶたびに)

| やること | コマンド |
| --- | --- |
| クイックマッチ(1ラウンド、店はランダム) | `/cg match start quick` |
| クイックマッチ(店を指定) | `/cg match start quick japanese` |
| ノーマルマッチ(中華→フランス→和食) | `/cg match start normal` |
| 一時停止 / 再開 | `/cg match pause` / `/cg match resume` |
| いまのラウンドをやり直す | `/cg match redo-round` |
| 強制終了 | `/cg match stop` |
| 得点の手動調整 | `/cg score add team-1 100`(マイナスも可) |
| 観戦(運営でなくても使える) | `/cg spectate [キッチンID]`、やめるときは `/cg spectate stop` |

流れ: 開始 → キッチンへテレポート → カウントダウン → ラウンド → 結果と休憩 → (ノーマルは次のラウンド) → 最終結果 → 元の場所へ戻る。

- 試合中に抜けた人が戻ると、同じキッチンに戻される
- 試合中はチームのメンバーを変えられない(名前と色は変えられる)
- 一時停止中は、調理のタイマーも止まり、設備は反応しない
- 試合中に `/cg kitchen reset` をすると、設備の中身だけが空になる(得点と注文はそのまま)
- 試合の終わりにオフラインだった人は、次に入ってきたときに持ち物が消えて元の場所へ戻る
- 試合のあと、参加者はアドベンチャーモードのまま。必要なら運営がゲームモードを戻す

## 5. 設定を変える

`/cg settings` でチェストの画面が開く。左クリックで増やし、右クリックで減らす。シフトを押しながらだと10倍変わる。変えたらすぐ `settings.yml` に保存される。試合中に変えた値は、次のラウンドから効く。

## 6. レシピを変える

`recipes.yml` を編集して `/cg reload`(試合中は不可)。書き間違いがあると、どこが間違っているか(例: `shops.chinese.processes[2].out: 未定義のアイテム 'meat_cutt'`)が表示され、前の内容のまま動き続ける。新しいアイテムを足したら、リソースパックにも同じ識別子のモデルと画像を足す。

## 7. 困ったとき

| 症状 | 確かめること |
| --- | --- |
| アイテムが紫と黒の模様になる | リソースパックが届いていない、または画像がない |
| 設備をクリックしても反応しない | 自分のチームのキッチンか。一時停止中やカウントダウン中ではないか |
| 試合が始まらない | チャットの理由を読む(チームが空、キッチンが足りない、スポーンがない など) |
| 設備の見た目が二重に出る | サーバーを再起動する(起動時に古い表示を消して作り直す) |
