# Minecraft Cooks 運営仕様書

**2026/11/22更新版**

ゲームのルールと数値をまとめた、運営向けの資料。ミニゲームを遊ばせている最中に「これってどういう決まりだっけ?」となったときに引く。準備や進行の手順は `運営ガイド.md`、作りの詳しい話は `design.md` を見る。

数値はすべて初期値。`/cg settings` の画面で変えられる。

## 1. ゲームの概要

- サーバーで遊ぶ、チーム対抗の料理**ミニゲーム**。一度キッチンを用意すれば、何回でも遊べる
- 5人1組のチームが、それぞれのキッチンで料理を作って、注文どおりに届ける。チームの中では協力し、チーム同士では得点を競う
- ミニゲーム1回ぶんを「試合」と呼ぶ。試合が終わったら、チームを分け直して、すぐ次の試合を始められる
- 4〜8チーム(20〜40人)が同時に遊ぶ。全チームに同じ順番で同じ注文が出る
- 店は3つ: **中華・フランス・和食**。店ごとに作る料理が3品ずつある
- 試合の形は2つ

| 試合 | 中身 | 順位の決め方 |
| --- | --- | --- |
| クイックマッチ | 1ラウンド。店は指定かランダム | そのラウンドの得点 |
| ノーマルマッチ | 3ラウンド(中華 → フランス → 和食) | 3ラウンドの合計点 |

## 2. 時間

| 項目 | 初期値 |
| --- | --- |
| カウントダウン | 5秒 |
| 1ラウンド | 5分 |
| ラウンド間の休憩 | 30秒 |

## 3. プレイヤーのルール

- 試合中はアドベンチャーモード。ダメージ・空腹・PvP はなし
- **持てるのは1つだけ**(ホットバーの1枠目)。インベントリを開く、持ち替える、オフハンドに移すことはできない
- 手がふさがっていると、食材箱からもらえない。設備から取り出すこともできない
- 仲間に渡すときは **Q で床に落とす**。落ちた物は、手が空いている人だけが拾える
- 床に落ちた物は、ラウンドの終わりに全部消える
- 自分のチームのキッチン以外の設備は、触っても反応しない
- 試合の開始時と終了時に、持ち物は空になる
- 途中で抜けた人が戻ると、同じチームのキッチンに戻る。代わりの人は入れない

## 4. 設備の使い方

| 設備 | 操作 |
| --- | --- |
| 食材箱(肉・魚・野菜・麺・米) | 素手で右クリック → 食材を1つもらう |
| まな板 | 食材を持って右クリックで置く → 素手で右クリックを**5回**で切れる → 素手で右クリックで取る。スニーク+右クリックで、切らずに取り戻す |
| フライパン・鍋4種・フライヤー | 食材を持って右クリックで入れる(**最大4個**)。時間がたつと自動で完成。素手で右クリックで取り出す(調理中なら、最後に入れた物が1つ戻る) |
| 皿(盛り付け台) | 部品を持って右クリックで載せる。料理の部品がそろうと、自動で完成品が手に入る。素手で左クリックで最後の部品が1つ戻る。素手で右クリックで載っている物の一覧が出る |
| 納品場所(1〜3) | 料理を持って右クリックで入れる → 左クリックを**3秒以内に2回**で送る。スニーク+素手で右クリックで、最後に入れた料理が1つ戻る |
| ゴミ箱 | 右クリックで、手に持っている物を捨てる |

### 自動で調理する設備のきまり

- 食材を足すと、タイマーは最初からやり直し
- 完成時間になったとき、中身がその設備のレシピと**種類も個数もちょうど一致**していれば完成品になる。違えば「失敗した料理」になる
- 完成したまま放っておくと「焦げ」になる
- 失敗した料理と焦げは、ゴミ箱に捨てるしかない

| 設備 | 完成まで | 完成から焦げるまで |
| --- | --- | --- |
| フライパン(焼く・炒める) | 8秒 | 8秒 |
| 茹で鍋 | 10秒 | 10秒 |
| 蒸し鍋 | 10秒 | 10秒 |
| 煮込み鍋 | 12秒 | 12秒 |
| 固め鍋 | 12秒 | 12秒 |
| フライヤー | 8秒 | 8秒 |

## 5. レシピ

同じ設備に同じ物を入れても、店によってできる物が変わる(例: 煮込み鍋に切った肉+切った野菜 → フランスならポトフ、和食なら肉じゃが)。いま遊んでいる店のレシピだけが使える。

| 店 | 料理 | 作り方 | 皿に載せる物 |
| --- | --- | --- | --- |
| 中華 | ラーメン | 麺→茹で鍋 / 肉→茹で鍋→まな板 / 野菜→まな板 | 茹でた麺+切った茹で肉+切った野菜 |
| 中華 | シュウマイ | 切った野菜+切った肉→蒸し鍋 | 蒸したシュウマイ |
| 中華 | チャーハン | 切った野菜+切った肉+米→フライパン | 炒めたチャーハン |
| フランス | テリーヌ | 切った肉(か切った魚)+切った野菜→固め鍋 | 固めたテリーヌ |
| フランス | ムニエル | 魚→フライパン→もう一度フライパン | よく焼いた魚 |
| フランス | ポトフ | 切った野菜+切った肉→煮込み鍋 | 煮込んだポトフ |
| 和食 | 天ぷら | 魚→まな板→もう一度まな板→フライヤー | 揚げた天ぷら |
| 和食 | 肉じゃが | 切った肉+切った野菜→煮込み鍋 | 煮込んだ肉じゃが |
| 和食 | おそば | 麺→茹で鍋 / 肉→フライパン | 茹でた麺+焼いた肉 |

レシピは `recipes.yml` で変えられる(`/cg reload` で反映。試合中は不可)。

## 6. 注文

- キッチンには常に**3件**の注文が出ていて、それぞれ納品場所1〜3に対応する
- 1件送ると、空いた枠に次の注文が出る
- 注文の中身は全チーム共通。「k 件目の注文」はどのチームでも同じなので、送った数が同じチームは同じ注文を見る
- 先に進むほど、1件の注文に入る料理の数が増える

| 段階 | 何件目から(k) | 料理の数 |
| --- | --- | --- |
| 1 | 0件目〜 | 1〜2個 |
| 2 | 6件目〜 | 1〜3個 |
| 3 | 14件目〜 | 2〜4個 |

- 料理はその店の3品から均等にランダム。同じ料理が重なることもある
- 注文の中身は、納品場所の上に浮かぶ文字で見える。サイドバーに全チームの順位と得点、ボスバーに残り時間が出る

## 7. 得点

注文に入っている料理の数を n とする。

- **満点** = 100点 × n × 倍率(n=1: ×1.0、2: ×1.1、3: ×1.2、4: ×1.3)
- **間違いの数** = 足りない料理の数 + 余計な料理・違う料理の数
- **その注文の得点** = 満点 − 間違いの数 × (満点 ÷ n)。0点より下にはならない
- **ラウンドの終わりの減点** = そのラウンドの合計点 × 0.25% × そのラウンドの間違いの総数(1点未満は切り捨て)

例: 注文が「ラーメン2個+チャーハン1個」(n=3、満点360点)に、ラーメン1個+シュウマイ1個を送った。足りないのがラーメン1・チャーハン1、余計なのがシュウマイ1で、間違いは3。得点は 360 − 3×120 = **0点**。

- 空のまま送ることはできない
- 運営は `/cg score add <チーム> <点>` で手動で調整できる(マイナスも可)

## 8. 同点のとき

初期値は「最後のラウンドの得点が高いほうが上」。設定で「間違いが少ないほうが上」「同じ順位のまま」にも変えられる。

## 9. チーム分け

- `/cg team auto` で、オンラインの人(不参加に指定した人を除く)をランダムに5人ずつ分ける。最大8チーム
- 5で割り切れない余りの人と、40人を超えたぶんは観戦になる
- 手で直したときは5人ちょうどでなくても開始できる(警告は出る)
- チームの色の初期値: 赤・青・緑・黄・紫・水色・橙・桃
- 試合中はメンバーを変えられない(名前と色は変えられる)

## 10. 観戦

`/cg spectate [キッチン]` で、スペクテイターモードでキッチンを見に行ける。運営でなくても使える。やめるときは `/cg spectate stop`。

## 11. 一時停止など

- `/cg match pause` 中は、調理のタイマーも止まり、設備は反応しない
- `/cg match redo-round` で、いまのラウンドをやり直せる
- サーバーを再起動すると、その試合は無効になる(続きからはできない)
